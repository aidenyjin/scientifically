# Scientifically

Duolingo-style science learning app for laptops. This repo is the shell only; course
content is generated by an AI model through `src/server/ai/` and validated against the
Zod schemas in `src/content/schema/`.

**Read `docs/PLAN.md` first.** It is the source of truth: fixed stack, layout, content
contract, question types, game rules, and milestones. Continue from the first unticked
milestone, tick boxes as you go, and commit after each milestone.

Before every commit: `npm run lint && npm run typecheck && npm test` must pass.

Key rules:
- `src/engine`, `src/game`, `src/content`, and exercise `grade.ts` files are pure TS
  (no React, DB, or `Date.now()` — use `src/lib/clock.ts`). Unit test them.
- API keys live only in `src/server/**` (import `"server-only"`). Never expose to the client.
- New question types copy the `multiple_choice` reference implementation.
- Do not build diagram question types or AI-marked free text (deferred).
- Record any decision not covered by the plan in the Decisions log at the end of `docs/PLAN.md`.
